# Phone Standardizer — Multi-Platform Client SDKs 🌐

Official client SDK layouts and OpenAPI 3.1 contracts for integrating the **Phone Standardizer** microservice and browser-side React `<PhoneInput />` component across polyglot enterprise stacks:

- **TypeScript / React (`sdks/typescript`)** — Typed client (`@jacob-white/phone-standardizer`) and headless `<PhoneInput />` with dynamic national formatting and country flag selection.
- **.NET 8 / C# (`sdks/dotnet`)** — `PhoneStandardizer.Client` targeting `net8.0` and `netstandard2.0`.
- **Go (`sdks/go`)** — Zero-dependency `phonestandardizer` client package.
