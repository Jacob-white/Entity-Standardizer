# Address Standardizer

Multi-national address standardization, offline spatial geocoding and cross-border entity resolution, as a Python
library, a CLI and an HTTP service with TypeScript, .NET and Go clients.

The project overview, install instructions and feature list live in the
[README](https://github.com/Jacob-white/Address-Standardizer#readme); this site holds the reference material.
